 
# 🍽️ Ohmyfood

**Ohmyfood** est une application web mettant en valeur des menus de restaurants gastronomiques, avec une interface moderne et responsive.

## 🚀 Fonctionnalités

- ✅ Interface **responsive** (mobile & desktop)
- ✅ Compatibilité avec les navigateurs modernes :
  - Chrome
  - Firefox

## 🛠️ Technologies utilisées

- HTML5
- CSS3

## 📁 Structure du projet

Ohmyfood/
├── CSS/ # Feuilles de style CSS
├── Images-et-textes-Ohmyfood/ # Images et contenus textuels des menus
├── index.html # Page d'accueil
├── a-la-francaise.html # Menu "À la française"
├── La-note-enchantee.html # Menu "La note enchantée"
├── Le-delice-des-sens.html # Menu "Le délice des sens"
└── palette-du-gout.html # Menu "Palette du goût"
